# Autonomous ML Research Agent — KuaiRand-Pure

TikTok TechJam 2026 submission (challenge 2.1). An LLM-driven agent that
autonomously runs the ML engineering loop — read the problem, inspect data,
engineer features, train and tune, evaluate, reflect and iterate — on the
KuaiRand-Pure recommendation benchmark, aiming to beat the official baseline
on the hidden test set.
